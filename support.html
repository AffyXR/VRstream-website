Support & Troubleshooting

VRstream is a local-network DLNA/UPnP media server. Most issues are related to network discovery, file access, or client compatibility.

Playback issues

  • Confirm the server is running and the address/port shown in the app are reachable from the client device.
  • Use a DLNA client that supports the media format. VRstream streams original files without transcoding.
  • For large files, ensure the client supports HTTP byte-range requests for seeking.
  • Restart the server after adding or removing shared folders.

File access issues

  • On Android, grant folder access through the Storage Access Framework prompts. VRstream does not request broad storage permission.
  • Re-add a folder if its contents changed or if the original grant expired.
  • Shared media files are never modified, moved, or deleted by VRstream.

DLNA connection issues

  • Ensure the phone/computer and the client are on the same local network.
  • Allow multicast traffic; SSDP discovery uses 239.255.255.250:1900.
  • If discovery is blocked, connect the client manually to the server address and port shown in the app.
  • Check that no firewall blocks the configured port (default 8200).
  • Stop and restart the server to re-announce ssdp:alive notifications.

Compatibility

  • Android, Windows, macOS, and Linux are supported. iOS/iPadOS scaffolding is included but may require additional setup.
  • VR headsets and players must support the media formats you share.
  • Production ads and premium purchases are disabled or unconfigured by default; billing requires Google Play Console setup.

Privacy and data

See the Privacy Policy for details on local storage, third-party SDKs, and deletion. Uninstalling the App removes local app data on Android.
