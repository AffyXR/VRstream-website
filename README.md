# VRstream Website

Public static website for [VRstream](https://github.com/AffyXR/VRstream), a local-network DLNA/UPnP media server for VR180, 3D, and regular video.

This repository contains only the public website files used for GitHub Pages. It does not contain the VRstream application source code.

## Pages

- `index.html` — project overview
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Use
- `support.html` — Support and troubleshooting
- `licenses.html` — Open-source and third-party notices

## Deployment

The site is deployed with GitHub Pages using GitHub Actions. The workflow is defined in `.github/workflows/deploy.yml`.

## Notes

- Replace placeholder contact and legal details before relying on the published pages.
- The app source code remains in the private `AffyXR/VRstream` repository.
- This repository intentionally contains no application source code, signing material, or secrets.
